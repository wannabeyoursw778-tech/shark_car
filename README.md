## Ishga tushirish

1. Kompyuteringizga Node.js o‘rnating.
2. Loyiha papkasini terminalda oching.
3. PowerShell’da `npm.cmd start` buyrug‘ini bajaring (`cmd.exe` oynasida `npm start`).
4. Brauzerda `http://127.0.0.1:3000` manzilini oching.

Qo‘shimcha kutubxonalar o‘rnatish shart emas. PowerShell’da portni o‘zgartirish uchun `$env:PORT='3001'; npm.cmd start` buyrug‘ini bajaring.
